# 🛒 ShopEase – E-Commerce Web Application

**ShopEase** is an e-commerce web application developed to provide users with an online shopping experience. The project focuses on product management, user authentication, and shopping cart functionality.

## 📌 Project Overview

ShopEase is a web-based shopping platform designed to demonstrate practical web development concepts, frontend design, backend functionality, and database management.

The project was initially developed with assistance from Replit.

## 🚀 Features

- User Registration and Login
- Product Listing and Management
- Shopping Cart Functionality

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YashC001/ShopEase.git
```

### 2. Navigate to Project Directory

```bash
cd ShopEase
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

Activate it:

**Windows**
```bash
venv\Scripts\activate
```

**Linux / macOS**
```bash
source venv/bin/activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Configure Database

Configure your database credentials in Django settings according to your local MySQL setup.

### 6. Apply Migrations

```bash
python manage.py migrate
```

### 7. Run Development Server

```bash
python manage.py runserver
```

Open your browser and visit:

```text
http://127.0.0.1:8000/
```

*These instructions assume a Django project. Update them if your Replit application uses a different framework or database.*
